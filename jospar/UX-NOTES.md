| Мәселе | Шешім |
|---|---|
| Телефонда атаулар мен көмекші мәтіндер ұсақ | Әдепкіде 19 px мәтін, 20 px атаулар, 16 px қосымша мәтін. Профиль → Баптауларда үш оқу өлшемі бар. |
| Әдеттің қатары мәтін арасында жоғалады | Жеке жалын белгісі және қатар саны. Нөлдік қатар сұр, белсенді қатар акцент түсті. Бейтарап бақылауда қатар есептелмейтіні түсіндірілген. |
| Қоржында мерзімді ауыстыру батырмасы атауды қысады | Тізімде белгілеу мен тапсырманы ашу қалады. Күнді ауыстыру тапсырманың ішіне көшірілді. Мерзімі өткен істер бөлек топта. |
| Қойындының таңдалған күйі көрінбейді | ARIA логикалық атрибуттары мәтін ретінде беріледі. Таңдалған қойынды, күндер және оқу өлшемі дұрыс ерекшеленеді. |
| Қосу әрекеттері бірнеше жерде қайталанады | Тұрақты мәзірдегі «+» — негізгі қосу орны. Бос бетте контекстік әрекет бар. |
| Мақсатта карточканың ішінде тағы карточка | Әр мақсатқа бір карточка. Өңдеу атаудың жанында, ішкі әдеттер мен қадамдар ашылып-жабылады. |
| Профиль тым ұзын, салыстыру жолдары қысылған | «Шолу / Аналитика / Баптаулар». Нәтижелер мен салыстырулар екі бағанды плиткаларда. |
| Қосу диалогы экран ортасында, алғашқы жолда артық фокус | Телефонда төменнен ашылатын парақ; тақырып, жабу және түсіндірмесі бар үш ірі әрекет. |
| Мәзір мен экран астында артық бос орын | Қолданба биіктігі динамикалық viewport-пен теңестірілген. Тек негізгі мазмұн айналады, мәзірдің биіктігі тұрақты. |
